# FSMobile

FSMobile ist eine installierbare Progressive Web App fuer mobile Arbeitsablaeufe im Bereich Fire Safety.

## Funktionen

- Zentrale Menueauswahl fuer Kalkulation, Pruefberichte und Wartungsanleitungen
- Installierbar als PWA auf iPad, Tablet, Smartphone und Desktop
- Offline nutzbar nach dem ersten Laden der App
- Pruefberichte mit dynamischen Eingabefeldern, Archiv und PDF-Export
- Import und Export von Berichtsdaten zur Wiederverwendung
- Kalkulationsberichte fuer Maengellisten, Bilddokumentation und Aufmasse
- Wartungsanleitungen direkt in der App abrufbar
- Optimierte Darstellung fuer die Nutzung auf dem iPad

## Bereitstellung

Nach einem Update die App einmal online oeffnen, damit die aktuelle Version fuer die Offline-Nutzung gespeichert wird.
